Node.js · Express · MongoDB · JWT
Backend API
  • JWT auth + 2FA + refresh token rotation · Role-based access control (user / admin)
  • REST API: auth, transactions, reports, users (admin), subscriptions
  • Claude Sonnet: Arabic NLP transaction extraction from natural language
  • RAG pipeline: MongoDB Atlas Vector Search + Arabic accounting knowledge base → context-injected Claude
  • Subscription middleware: enforces 100-txn Free limit, blocks expired trials
5
Meta Cloud API · Saudi Dialect NLP
WhatsApp Bot
  • Meta Cloud API webhook — no BSP middleman, no monthly platform fee
  • "شريت قهوة من ستاربكس بـ٢٥" → logs 25 SAR, category: Food/Coffee, merchant: Starbucks
  • Commands: كم رصيدي؟ · تقرير الأسبوع · تقرير الشهر

Moyasar · Mada · Sadad · Apple Pay
Payment Gateway & Subscription Billing
  • Mada (مدى) and Sadad (سداد) — mandatory for Saudi SME users — plus Apple Pay and Visa/Mastercard
  • Free → 14-day Professional trial → 149 SAR/month charge → 499 SAR/month Enterprise
  • trial_end timestamp enforced at API middleware — card not charged until trial expires
  • Webhook: payment.succeeded → upgrade, payment.failed → 3-day grace → downgrade

MongoDB Atlas Vector Search · Claude · voyage-multilingual-2
Arabic Accounting RAG Knowledge Base
  • ArBanking77 (39K Arabic banking queries), AraFinNews (212,500 Gulf financial articles), SAHM benchmark
  • 500+ synthetic Saudi SME WhatsApp-style transaction records generated via Claude
  • Native to MongoDB cluster — no separate Pinecone cost. User-generated flywheel post-launch.

Section 06

Arabic Dataset Strategy

Three layers ensure the AI chat answers Saudi-specific accounting questions correctly from day one — and gets smarter as the product grows.

01
Open Datasets
Loaded at Start

ArBanking77 — 39,000 parallel queries in MSA and Saudi dialect, labeled with 77 banking intents. Ideal for transaction intent classification.

AraFinNews — 212,500 Gulf financial news articles from Argaam.com. Covers VAT, invoice language, and Saudi accounting terminology in Arabic.

SAHM Benchmark — 14,380 expert-verified Arabic financial NLP instances covering accounting and Shari'ah-compliant financial reasoning.

Saudi Open Data Portal (open.data.gov.sa) — SAMA, ZATCA, and Ministry of Finance datasets directly relevant to Saudi SME accounting context.

ArBanking77 AraFinNews SAHM Benchmark Saudi Open Data
02
Synthetic Dataset
Generated via Claude

500+ realistic Saudi SME WhatsApp-style transaction messages generated using Claude with a structured prompt — covering expense logging, income recording, VAT queries, payroll mentions, and balance inquiries, all in Saudi Arabic dialect with SAR amounts.

Output as labeled JSON: { message, intent, amount, currency, category, date_reference }

This fills the gap no public dataset covers: informal WhatsApp-style accounting messages from Saudi SME owners.

03
User-Generated
Flywheel

Every real transaction logged through the app or WhatsApp bot post-launch becomes a labeled training record. After 30 days of production traffic, Hesabi AI has a Saudi-specific accounting dataset more valuable than any public corpus.

This is a compounding competitive advantage built into the architecture from day one — the product improves automatically as your user base grows. Competitors cannot replicate this without your users.
